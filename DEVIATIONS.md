# Deviations and limitations

1. **V6 seed44 rerun.** Original failed-resume seed44 is excluded. The retained rerun selects epoch35. The nine recorded core file hashes match all four available rerun wrappers, so the exact wrapper ZIP remains unidentifiable from those hashes alone.
2. **Earlier V6 parity gate.** Seed44’s approximately 4.65e−3 score difference exceeded the original max 2e−3 gate. The archived contracts and patch record a change to max 1e−2 / mean 1e−3 before adapter training. This amendment is not described as proof of bitwise equivalence.
3. **Earlier executed worker.** The executed worker matches the runtime contract. The earlier distributed ZIP is retained separately; package-vs-runtime source differences are documented.
4. **ETA formatting patch.** The reported earlier `reporting.py` patch affected runtime-estimate formatting. The original deviation note is retained when available; this does not establish that every later wrapper was identical.
5. **V3.2 H7 report formatting.** After test predictions were saved, printing absent prior-study parity values raised a TypeError. The documented in-memory patch allowed reporting/analysis to finish; the prior parity CSV contains NaN, not a performed parity comparison.
6. **Compacted weights.** Training snapshots were removed after selected adapter export. The source archives retain selected adapter NPZs and frozen-base provenance; these are outside Git. Reconstructing a prediction from weights requires the complete compatible base, adapter, capture code and metadata, not only a summary CSV.
7. **Historical H26.** H26 comes from an earlier execution campaign. The recorded effective batch is16; campaign chronology should not be rewritten as an established batch-size difference.
8. **Exploratory evaluation.** The test set was inspected in earlier rounds; current context-length and adapter follow-ups are exploratory. Bootstrap CIs condition on three fixed trained seeds. The ten main Holm tests are corrected separately per base; secondary and interaction intervals are nominal.
9. **H7/H13 evaluator recovery.** Two original metadata dependencies were restored. A cached/full-pipeline score guard failed under the original numerical flags; strict-FP32 evaluation passed without changing the original parity tolerance or retraining. This does not eliminate all floating-point error.
10. **H13 re-zipped logs.** A browser-generated ZIP of the downloaded folder differs from the old server ZIP checksum. Earlier source-member checks verified the original log contents. Do not describe this solely as training-log mutation or use the obsolete outer checksum as a match.
11. **Local release transformations.** Duplicate upstream source ZIPs are stored once, lengthy text logs are losslessly gzipped, and dense curves/cache records are omitted from Git. Any security redaction is listed separately. Source archives are not changed.
