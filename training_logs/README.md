# Training logs (plain text)

Readable copies of the training logs of every reported run, gathered in one folder so they open directly in the browser.
Files ending in `.gz` in the original run folders were decompressed with `gzip -d` without any other change; plain-text sources were copied unchanged.
`SHA256SUMS.txt` lists the hash of each file here and of its source file in the release, so each copy can be checked against the original.

The mmengine logs (all files except AdaLEA) record, every 20 optimizer steps, the loss and its components, learning rate, and GPU memory (`Epoch(train)` lines), and the validation metrics after each epoch (`Epoch(val)` lines). The AdaLEA log records the loss during each epoch and the validation mAUC after each epoch.
H7, H13, and AdaLEA keep all three seeds in one file, as in the original runs.
